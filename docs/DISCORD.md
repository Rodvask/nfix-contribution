```text
# 📡 Proposal: community trade telemetry for NostalgiaForInfinity

**The problem:** NFI has dozens of entry signals refined over years of live trading — but no signal performs the same on every exchange, in every regime, forever. When a tag starts failing, or the crowd piles into the same pair at the worst moment (blow-off tops), each trader discovers it alone, with their own money.

**The proposal:** build TOGETHER an opt-in telemetry system pooling anonymous, aggregate-only outcomes so we can see which signals earn their keep:
• Win rate per entry tag × exchange
• Weekly trends (decaying tag or just one bad week?)
• Shared evidence base instead of anecdotes
```
